Leonida Platinum Road — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a roadmap to the platinum, the one missable trophy flagged, and a checklist saved in your browser with export/import, kind filters and a spoiler-safe mode. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no network: `app/` is plain static files. `app/data/trophies.json` holds the 55 official trophies with their guides and sources.
